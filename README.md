# 💤 Sleep Detection System

A real-time sleep detection system built using **Python** and **OpenCV** that monitors eye activity through webcam input and detects whether a person is **ACTIVE** or **SLEEPING**.

---

## 🚀 Features
- 👤 Face detection using OpenCV Haar Cascades  
- 👁️ Eye detection for sleep analysis  
- 📹 Real-time webcam monitoring  
- ⚡ Stable detection using frame-based logic  
- 🖥️ Live status display (ACTIVE / SLEEPING)

---

## 🛠️ Tech Stack
- Python  
- OpenCV  
- NumPy

## ▶️ How to Run

### 1. Clone the repository
git clone https://github.com/tharunkorla/sleep-detection-python.git  
cd sleep-detection-python  

### 2. Install dependencies
pip install opencv-python numpy  

### 3. Run the project
python main.py  

---

## 📸 Output
- 🟢 ACTIVE → Eyes detected  
- 🔴 SLEEPING → Eyes not detected for multiple frames  

---

## ⚠️ Limitations
- Works best in good lighting conditions  
- Basic implementation (not AI-based)  
- Accuracy depends on eye detection
